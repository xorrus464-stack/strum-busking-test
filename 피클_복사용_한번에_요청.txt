첨부한 STRUM_Pickl_버스킹기타_전체코드.zip의 전체 파일과 PICKL_HANDOFF.md를 먼저 읽어줘.
목표는 내가 기존에 사용한 AeroBand 기타 학습 사이트 STRUM · 나의 버스킹 여정을 독립적으로 복원·개선하는 거야.
절대 https://aeroband-busking-jc.actualtide8.chatgpt.site/ 원본 사이트를 수정, 삭제, 덮어쓰기, 재배포하지 마. 새 프로젝트의 테스트 주소에서만 실행해.
내 유튜브 원본 재생목록은 https://www.youtube.com/playlist?list=PLdOy20BJp9XElDHDvAJI6mUG48BmfDX-y 이야.
확보된 데이터는 원본 영상 번호 1~211개 슬롯, 이전 대화에서 확인한 곡 정보 25건(가수 미확인 1건 포함), 별도 추천곡 1건이야. 과거 원본 사이트의 선별곡 152곡 전체는 아직 확보되지 않았고 42개 접근 불가 영상의 정확한 번호도 몰라. 빈칸을 임의로 생성해서 152곡이 완성된 척하지 마.
특히 원본 #6에는 곡 7개, #65에는 곡 2개가 연결되고, #163은 제외해. #172 '날씨가 좋고 바람도 좋아' 가수는 미확인이니 추측 금지. 기존 곡 ID와 원본 번호 순서, 수정·연습 기록, 숙련도를 보호해.
주요 필수 기능: 곡명·가수·원본 번호 통합 검색, 곡 추가/수정/키/남자키/코드/스트로크/검수 상태, 원본 유튜브 재생목록, 사이트 내 영상 보기와 별도 음악 듣기, 20~30분 초보 루틴, Easy Chord/SimplifyChord와 정식 코드 구분, 연습 타이머, 40~180 BPM 메트로놈, 숙련도 4단계, 매일 연습 기록, 첫 버스킹 세트리스트, JSON/CSV 내보내기/병합, 갤럭시 모바일 화면 지원이야.
음악 듣기는 합법적인 사용자 소유 파일·허용된 오디오만 직접 재생하고, 유튜브에서 음원을 무단 다운로드하거나 숨겨서 오디오만 추출하지 마. 자동분석한 코드와 남자 키는 청음 검수 전까지 '미확정'으로 표시해.
어떤 정보든 출처 없이 추측하지 마. 기존 데이터 덮어쓰지 말고, 전체 교체/초기화 전 JSON 자동 백업과 확인 과정을 유지해. 유료 결제나 API 키 연결도 내 승인이 있어야 해.
먼저 python tools/verify_data.py, node tools/smoke_static.js, node --check src/app.js를 실행한 뒤, 실제 PC와 갤럭시 Android Chrome에서 곡 검색(#6, #65, #172), 영상 보기, 음악 듣기, 루틴, 타이머, 메트로놈, 연습 기록 저장, 데이터 백업·가져오기를 검수해.
완료되면 반드시 ① 완성/부분/미확인 항목 ② 실제 테스트 근거 ③ 수정 파일 ④ 남은 152곡 복원 과제 ⑤ 기존 사이트/기록에 미친 영향(없어야 함) 을 한국어로 보고해줘.
