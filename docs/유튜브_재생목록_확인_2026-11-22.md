## 2. 확인한 증거

1. `GET https://www.youtube.com/playlist?list=…` → **HTTP 200**, 2.24MB HTML, `ytInitialData`에 영상 항목 포함.
2. 같은 응답의 `browseEndpoint.params=wgYCCAA=`(사용할 수 없는 동영상 표시)로 조회 → 항목 **210개**, 그중 **42개는 제목이 비어 있고 `조회수 없음`**으로 표시(삭제·비공개 영상).
3. `GET https://www.youtube.com/oembed?url=…/playlist?list=…` → **401 Unauthorized** (같은 시각 단일 공개 영상 oEmbed는 200). 즉 일반 공개 재생목록과는 다른 공개 범위(일부 공개)로 보이나, 이는 추정입니다.
4. 사이트 안 iframe(`youtube-nocookie.com/embed/videoseries?list=…`)을 실제 페이지에 삽입해 확인 → 플레이어에 `이 동영상은 볼 수 없습니다.`
   - 같은 환경에서 공개 영상 단독 임베드(`dQw4w9WgXcQ`, `AvQOisDWy10`)도 같은 문구가 나오고, `watch` 페이지는 `playabilityStatus = LOGIN_REQUIRED`("로그인하여 봇이 아님을 확인하세요")였습니다. **따라서 임베드 실패가 재생목록 공개 범위 때문이라고 단정할 수 없습니다.**
5. 브라우저 `fetch`/브라우저 자동화 없이도 목록이 읽혔으므로, 목록 데이터 자체는 열람 가능한 상태입니다.
