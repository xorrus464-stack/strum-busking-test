두 파일 모두 16kHz 모노 AAC 16kbps(카카오톡 음성 규격)라 3kHz 이상이 거의 지워져 있고, 코드 판별은
저역(베이스·기타 몸통) 중심 크로마로 했습니다. 그래서 **7th·sus·aug 같은 색채 코드와 마디 안 패스 코드는
확신도가 낮습니다.**

## 2. 측정 방법

1. `ffmpeg` 로 22.05kHz 모노 WAV 변환
2. `librosa.effects.hpss` 로 하모닉 성분 분리 → `chroma_cqt`(fmin C2, 36 bins/octave) 크로마
3. 4박 격자: 온셋 강도 격자 탐색으로 마디 길이·위상 고정 (30초 창 6개에서 값이 흔들리지 않는지 확인)
4. 마디별 크로마를 12근음 × 7화음(maj·min·7·maj7·m7·dim·aug) 템플릿과 비교(코사인) + Viterbi 스무딩
5. 도입 구간은 0.5초 단위 상위 3후보를 눈으로 대조하고, FFT 스펙트럼 피크로 실제 음(예: F3·A3·C#4)을 확인
