## 1) 최적의 14버튼 배치 계산 + 전곡 카포·운지 재매핑

### 규칙과 계산 방법
- 에어로밴드 앱 규칙: **7개 루트 열 `C·D·E·F·G·A·B` 마다 버튼 2개**, 각 열은 그 루트 코드 안에서만 선택.
- 각 열의 후보 = 3화음 2개 조합 `{장3화음+단3화음, 장3화음+감3화음, 단3화음+감3화음}` → **3⁷ = 2,187가지 전수 탐색**.
- 곡마다 카포 0~11을 모두 돌려 (남는 코드 종류 → 남는 마디 수)가 최소인 카포를 고른 뒤,
  ① 슬롯 없이 완주하는 곡 최대 → ② 남은 슬롯 합 최소 → ③ 슬롯 코드가 나오는 마디 최소.
- 7th·sus·add·6은 지금까지처럼 3화음 버튼으로 근사하고, 감5화음(m7♭5·dim)·증5화음(aug)만 감3화음/슬롯으로 다룹니다.
- 도구: `tools/optimize_btn14_2026_11_27.py` (재실행: `python3 tools/optimize_btn14_2026_11_27.py --write`)

### 결과 — 7열 모두 장3화음+단3화음
| 자리 | 1열 | 2열 | 3열 | 4열 | 5열 | 6열 | 7열 |
|---|---|---|---|---|---|---|---|
| 위 줄 | **C** | **Dm** | **Em** | **F** | **G** | **Am** | **B** (← Bdim) |
| 아래 줄 | **Cm** | **D** | **E** | **Fm** | **Gm** | **A** | **Bm** |

- **슬롯 없이 완주 132 → 134곡**, 남은 슬롯 **47 → 39개**(같은 방법으로 기존 배치를 다시 계산하면 46개).
- 상위 5개 배치(전수 계산):

| 배치 | 완주 곡 | 슬롯 합 | 슬롯 코드가 나오는 마디 |
|---|---|---|---|
| **C·Cm / D·Dm / E·Em / F·Fm / G·Gm / A·Am / B·Bm (채택)** | **134** | **39** | **86** |
| … F·Fdim … (F열 감3화음) | 134 | 41 | 89 |
| … G·Gdim … | 133 | 44 | 94 |
| … Bm·Bdim (기존) | 132 | 46 | 97 |
| … Fdim·Gdim … | 132 | 47 | 98 |

- **Bdim → B**: `Bdim` 은 161곡에서 **0회** 사용. `B`(장3화음)로 바꾸면 B 코드를 쓰는 곡이 버튼으로 잡힙니다.
- **Bdim → B7 대안 검토**: 악보의 B 루트 코드는 **B(장3화음) 195마디 vs B7·B9 등 7화음 68마디**.
  B7 버튼은 B7을 정확히 잡는 대신 보통 B 코드 195마디에 7음을 더해 울리게 되고, 진행 커버리지(완주 곡)는
  B와 B7이 같습니다 → **많은 쪽을 정확히 잡는 B를 채택**.
- 카포 0~7 창에서 다시 계산해도 채택 배치가 1위(133곡·43슬롯)임을 함께 확인했습니다.
- Bdim이 맡던 감5화음(m7♭5·dim)은 슬롯으로 옮겨 실제 코드 이름·운지를 표시합니다.
- **남자키(sound)와 연습 단계(stage)는 바꾸지 않았습니다.** 카포는 슬롯이 실제로 줄어드는 **3곡**만 옮겼습니다
  (Stay With Me 5→4, BIG Na 3→2, 너의 모든 순간 2→1). 나머지는 이미 맞춰 둔 폼을 유지합니다.

  "앱 **Easy Chord → 고급 설정**에서 왼쪽부터 C·D·E·F·G·A·B 열 순서, 위 줄·아래 줄 그대로 맞추세요" 문구와 함께
  그 곡이 쓰는 버튼은 진하게, 안 쓰는 버튼은 흐리게 표시합니다.

  같은 열의 두 버튼은 같은 색입니다(앱 화면과 같은 색 구분).

## 2) 악보 전체 + MR 재생 중 마디·코드 실시간 색깔 빛나기

- 악보 모달은 섹션별 **모든 마디를 한눈에** 보여주고, 마디마다 **시작 시각(0:14)** 을 적습니다.
- 악보 위에 **14버튼 바를 sticky**로 붙여, 스크롤해도 지금 코드 버튼이 함께 보입니다.
- MR(로컬 MP3 `currentTime` / YouTube `getCurrentTime()`) 재생 중에는
  · 지금 마디가 **그 코드 열 색 테두리 + 빛**으로 표시되고,
  · 그 마디의 코드 버튼이 **배치표와 위 14버튼 바에서 같은 색으로 빛납니다**.
  · 재생을 지나온 마디는 살짝 흐려집니다(카라오케식 진행 표시).
  · "6마디 · Bm 재생 중" 처럼 지금 마디를 글자로도 보여주고, '따라가기'를 끄면 화면이 따라 스크롤하지 않습니다.
- 마디 타임스탬프는 세 단계로 채웠습니다(`tools/apply_chart_timing_2026_11_27.py`).

| 방식 | 곡 수 | 근거 |
|---|---|---|
| `section` 실측 | 13곡 | 악보 섹션 이름에 적힌 실제 구간(`도입 (0:02–0:22)` 등)에서 마디 시각을 계산 |
| `bpm-local` 실측 | 5곡 | 저장소 `media/*.mp3` 실제 길이 + BPM + librosa로 잡은 첫 박 오프셋(예: Good Bye-Bye 246.6초·첫 박 0.93초·마디 2.697초) |
| `bpm-yt` 추정 | 141곡 | BPM·박자로 계산한 추정값 + **안내 배지** |
| `none` | 2곡 | BPM 미확인 — 타임라인을 표시하지 않음 |

- 유튜브 MR 곡에는 배지를 그대로 표시합니다:
  **"유튜브 MR은 전주·간주 길이에 따라 오차가 날 수 있어요. 녹화 음원을 주시면 정확히 맞춰드립니다."**
- 저장소 음원이 곡 길이보다 짧은 악보(Good Bye-Bye 28마디, 死別 17마디, 생각을 멈추다 보면 7마디)는
  곡이 길면 **악보 마디가 처음부터 다시 돌아가며 표시**된다는 안내를 함께 적었습니다.

## 3) 마디 클릭 → 그 마디부터 재생

- 악보의 아무 마디나 누르면(모바일 터치 포함) 그 마디 시작 시각으로 점프해 바로 재생합니다.
  - 로컬 MP3: `audio.currentTime = 시작 시각` (아직 버퍼가 없으면 seekable 범위가 생길 때까지 재시도)
  - YouTube: IFrame API `player.seekTo(초, true)` + `playVideo()`
  - MR이 다른 곡을 재생 중이면 그 곡의 MR로 바꿔 재생하고, MR이 없으면 이유를 알려 줍니다.
- YouTube 재생을 위해 **IFrame Player API**로 바꿨습니다. 미니 플레이어 안에 **보이는 플레이어**를 그대로 두고
  (숨김 재생 없음), API를 못 불러오면 기존 임베드 iframe으로 자동 대체합니다.

## 4) MR 배속 (음정 유지)

- 미니 플레이어에 **0.5x · 0.7x · 0.85x · 1.0x** 버튼.
- 로컬 MP3: `audio.preservesPitch = true` + `playbackRate` (음정 유지, 템포만 변경).
- YouTube: `player.setPlaybackRate()` — YouTube가 지원하는 배속이 0.5·0.75·1·1.25배로 제한되어
  0.7·0.85는 가장 가까운 **0.75x**로 적용하고, 버튼 옆에 실제 적용값(`0.75x · YouTube`)을 표시합니다.
- 키 조절(반음 −6~+6)과 함께 켜도 서로 간섭하지 않습니다(템포는 요소, 음높이는 WebAudio).

### 브라우저 검증에서 마디 이동이 실제로 되는지 확인한 방법
- e2e 서버에 GitHub Pages와 같은 **Range(206) 응답**을 넣었습니다. 이게 없으면 브라우저가 오디오를
  seekable로 보지 않아 `currentTime` 설정이 무시됩니다(실제 배포 환경은 Range를 지원).
- 앱도 이 경우를 대비해 **seekable 범위가 생길 때까지 짧게 재시도**합니다.
- **YouTube 경로**(`player.seekTo`·`player.setPlaybackRate`)는 브라우저 안에서 IFrame API를 테스트 더블로
  바꿔 호출 인자를 확인했습니다(마디 8 클릭 → `seekTo(24.0, true)`, 0.7x → `setPlaybackRate(0.75)`).
  검증 환경의 헤드리스 브라우저는 유튜브 영상 재생 자체가 진행되지 않아(코덱·자동화 제한) 실제 소리 재생은
  확인하지 못했습니다 — 휴대폰에서 한 번 확인해 주세요. API를 못 불러오면 기존 임베드로 자동 대체됩니다.
