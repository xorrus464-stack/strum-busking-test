## 4. MR(보컬 제거) 제작

### 4-1. 어떤 도구를 썼나

| 후보 | 이 환경에서의 결과 |
|---|---|
| `demucs` / `audio-separator` / `spleeter` | **설치 불가** — torch 휠이 539MB인데 작업공간 파일 하나의 상한이 512MiB(`File too large`). RAM도 3.6GB뿐 |
| **UVR MDX-Net (ONNX) 직접 실행** | **채택** — `onnxruntime`은 이미 설치돼 있어, audio-separator의 MDX 파이프라인(STFT → ONNX → iSTFT)을 numpy로 그대로 옮겨 돌렸습니다(`work/goodbye-bye-1126/mdx_onnx_sep.py`) |
| 모델 | **UVR-MDX-NET-Inst_HQ_5** (`md5 1b124d67…`, 입력 4×2560×256, n_fft 5120·hop 1024·compensate 1.01) |

HQ_3·Kim_Inst(4×3072×256)도 받아 시험했지만 이 RAM(3.6GB)에서는 `std::bad_alloc`으로 죽어 쓸 수 없었습니다.

### 4-2. 후처리 — "기타 소리를 살린다"

모델 출력만 쓰면 보컬이 없는 구간까지 기타가 함께 깎이고, 4kHz 위의 기타 밝기(스트럼의 공기감)가 -14.7dB까지 죽었습니다. 그래서 두 가지만 더했습니다(`work/goodbye-bye-1126/refine_mr.py`).

1. **보컬이 없는 구간은 원음 그대로**: 보컬 스템의 프레임 에너지가 최대치보다 42dB 이상 작은 프레임은 모델 출력 대신 **원래 녹음**을 그대로 씁니다(200ms 스무딩, 전체 프레임의 8.8%).
2. **4.5kHz 위는 보컬을 55%만 제거**: 치찰음(ㅅ·ㅆ)을 조금 남기는 대신 기타의 밝기를 지킵니다.

## 5. 악보 재세팅 — 이 녹음 키 B♭, C폼 · Capo +3

| 항목 | 이전(seed v24) | 지금(v25) |
|---|---|---|
| 곡 카드 원곡 키 / 남자키 | B♭ / **F** | B♭ / **B♭** (녹음이 원곡과 같은 조) |
| 악보 원곡 키 / 남자키 / maleShift | B♭ / F / 5 | B♭ / **B♭** / **0** |
| Capo · 폼 | +0 · F폼 (F·G·Em·Am·C) | **+3 · C폼** (C·D·Bm·Em·G) |
| 실제 울리는 코드 | F·G·Em·Am·C | **E♭·F·Dm·Gm·B♭** |
| 손으로 잡는 코드(슬롯) | 0 | **0** (14버튼만으로 완주) |
| BPM | 89 | 89 (실측 89.10) |

**왜 C폼 Capo +3인가**: C폼에서 Capo +3을 대면 C→E♭, D→F, Bm→Dm, Em→Gm, G→B♭로 울려 이 녹음의 코드와 정확히 겹치고, 쓰는 버튼 5개(C·D·Bm·Em·G)가 모두 14버튼 안이라 손 코드가 0개입니다. 공개 코드표(GuitarTabsExplorer · Capo 3 · Key C — Cadd9·Dsus·Bm·Em·G)도 같은 폼이라 근거가 일치합니다.

**마디 카드(28마디)**: 공개 코드표의 절 순서를 4박 마디로 옮기고, 녹음 실측 코드 어휘와 맞는지 확인했습니다.

| 절 | 마디 | 버튼 → 실제 울리는 코드 |
|---|---|---|
| Intro | 4 | C·D / Bm·Em / C·D / Bm·Em → E♭·F / Dm·Gm 반복 |
| Verse | 4 | 같음 |
| Pre | 4 | C·Em / G·D / C·Em / G·D → E♭·Gm / B♭·F 반복 |
| Chorus | 8 | C·D / Bm·Em / C·D / G ×2 → E♭·F / Dm·Gm / E♭·F / B♭ |
| Bridge | 6 | C / Em / C·Em / D / C / G → E♭ / Gm / E♭·Gm / F / E♭ / B♭ |
| Outro | 2 | C·D / G → E♭·F / B♭ |

> 마디 배치는 확인한 코드표를 4박 카드로 정리한 **연습용 배치**입니다. 실제 녹음의 마디 단위 코드 변화는 리버브·아르페지오 때문에 자동 검출 신뢰도가 낮아(마디 확신도 0.4~0.6) 악보 화면의 `basis`에 그 사실을 적었습니다.

## 8. 남은 것

- **가사·멜로디 청음 검수는 하지 않았습니다.** 마디 배치는 공개 코드표 + 실측 코드 어휘 대조까지입니다.
- 기기(localStorage)에 예전 값이 남아 있는 경우 곡 카드의 `공개 영상(…)` 표기는 병합 규칙상 예전 문구가 그대로 남을 수 있습니다(시드 값은 `공개 영상(남자 커버)`). 키·카포·악보·음원은 새 값으로 반영됩니다.
- 이 녹음은 화면 녹화에서 뽑은 191kbps AAC 원본이라 스튜디오 음원보다 음질이 낮습니다. 연습용으로는 충분하지만, 더 좋은 원본을 주시면 같은 과정으로 다시 만들 수 있습니다.
- MR은 4.5kHz 위 치찰음을 55%만 지웁니다(기타 밝기 유지 목적). 보컬 잔향이 거슬리면 그 비율을 1.0으로 올려 다시 렌더하면 됩니다(`work/goodbye-bye-1126/refine_mr.py`).
- 예전 남자키(F, -5반음)로 치고 싶으면 악보를 F폼 Capo 0으로 되돌리고 미니 플레이어에서 MR을 -5키로 내리면 됩니다. 지금 악보는 이 녹음(B♭)에 맞춰져 있습니다.
