# 기존 STRUM 사이트의 152곡을 정확하게 되살리는 방법

## 현재 알려진 상황
- 원본: https://aeroband-busking-jc.actualtide8.chatgpt.site/
- 사이트 화면에는 **나의 첫 세트리스트 152**라고 표시됨.
- 원본 Sites 내부 소스와 노래 배열, 개인 연습 기록에 대한 관리자 권한을 이 코드 패키지가 가진 것은 아님.
- 따라서 152곡을 추측해서 채워 넣거나 실제로 사용하지 않은 YouTube URL을 생성하면 데이터가 오염됨.

## 방법 A: 기존 Sites 편집 화면에서 가져오기 (우선 권장)
1. 원본 사이트를 만든 ChatGPT 대화/편집 화면을 엽니다.
2. 프로젝트의 실제 파일 목록을 열고 곡 배열(`songs`, `playlist`, `tracks`, `setlist`, `songLibrary` 등)과 **원본 211개 영상 번호/URL 데이터**를 찾습니다.
3. 데이터가 있다면 JSON 또는 CSV로 내보냅니다. 이때 제목·아티스트·원본 번호·유튜브 링크·연습 기록·남자 키·숙련도·메모를 함께 저장합니다.
4. 이 복원본을 연 뒤 `백업·설정 → 가져오기`에서 **병합**합니다. 기존 작업 결과를 덮어쓰지 않고 테스트합니다.
5. 실제 152곡이 들어왔는지 **곡 라이브러리에서 확인**하고, 원본 #6·#65의 다곡 분리 여부 및 #163 제외를 확인합니다.

## 방법 B: GitHub 원본 저장소가 있는 경우
1. 원본 사이트를 GitHub로 내보낸 저장소의 `src`/`data` 안에서 곡 데이터를 찾습니다.
2. JSON/TS/JS 배열을 `data/songs.seed.json`과 비슷한 형태로 변환합니다.
3. 키 정보는 근거가 없으면 `미확정`, 코드 정보는 검수 상태를 별도 기재합니다.
4. `python tools/generate_seed.py`는 기본 시드를 **기존 검증된 25곡으로 재생성하므로** 변환 데이터를 덮어쓸 수 있습니다. 새로운 데이터로 교체하려면 `src/seed.js`도 함께 갱신해야 하며, 단순히 이 스크립트만 실행하면 안 됩니다.

## 다른 기기에서 사용하기
- 앱은 별도의 서버 DB가 없는 정적 웹앱입니다.
- 전화기를 바꿀 때 `백업·설정 → 전체 JSON 백업` 파일을 새 기기에 저장한 후 새 사이트에 가져오세요.
- 단순히 홈페이지 주소를 공유해도 연습 기록은 공유되지 않습니다.
