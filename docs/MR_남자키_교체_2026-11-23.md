# 여자 원곡 → 남자키 MR · 남자 풀커버 영상 정리 (2026-11-23, seed v20)

주성 님 지시: "여자 원곡은 남자키(-5키) MR로, 음악 영상은 남자 완창 커버로, MP3 반주는 사이트에서 키 조절까지."
이 문서는 그중 **MR·영상 교체 근거**를 남긴다(키 조절 기능은 `src/pitch-worklet.js` · `tools/pitch_test.py`).

## 절차

1. YouTube 검색으로 곡별 후보 수집 — `"{곡명} {가수} 남자키 MR"`, `"{곡명} 남키 노래방"`, 필요하면 `"{곡명} 남자 키"`·`"-5키 MR"`.
2. **YouTube oEmbed HTTP 200** 으로 영상 존재·제목·채널 확인.
3. **임베드 재생 확인** — 앱과 같은 iframe 플레이어 기준. 서버에서 `https://www.youtube.com/embed/{id}` 를 우리 사이트 Referer로 받아 `playabilityStatus.status == OK` + `playableInEmbed == true` 인지 보고, 통과한 후보는 라이브 페이지 임시 확인 페이지(`mrcheck-temp.html`)의 YouTube IFrame API로 실제 `PLAYING` 상태까지 확인했다.
4. **TJ노래방 공식 채널 제외** — 임베드가 막혀(오류 150, "동영상 소유자가 다른 웹사이트에서 재생할 수 없도록 설정") 앱에서 재생되지 않는다. 실제로 TJ의 `[TJ노래방 / 남자키]` 영상이 곡마다 검색 상위에 올라오지만 전부 제외했다.
5. 같은 곡이 여러 항목(예: 「나의 X에게」 4개 항목)이면 **같은 MR**을 쓴다(`verify_data.py` works 규칙).

## 확인하지 못한 것

- **실제 키(반음) 실측은 하지 않았다.** 유튜브 음원 추출이 금지 조건이라 오디오 분석을 하지 않았고, `남자키`·`-5키`·`남Key` 같은 **제목 표기와 채널 관행**을 근거로 골랐다. 표기와 실제 키가 어긋나는 영상이면 악보의 Capo를 ±1 조정해야 할 수 있다.
- 「생각을 멈추다 보면」·「사별」·「서, 어른」은 남자키 MR이 없어 원키로 남겼다. 나중에 남자키 MR이 확인되면 mrNote의 `[원키 MR · -5키 필요]` 를 지우고 교체하면 된다.
- 임베드 확인은 2026-11-23 기준이다. 영상 소유자가 임베드 설정을 바꾸면 다시 막힐 수 있다(앱에는 'YouTube ↗' 링크가 함께 있다).
