- **부분 확인(partial)**: 원키·BPM·코드 후보가 있어 4박 마디 카드 악보를 만들었습니다. 코드는 공개 코드표/자동분석 후보이고 **마디 배치·박자·세부 코드는 청음/정식 악보 대조 전**입니다. 원키는 남성 원곡이면 그대로(이조 0), 여성 원곡만 −5반음 규칙을 따랐습니다.

## 곡별로 확인한 값과 판단

- **#2 Ten Thousand Hours**: BPM은 사이트별 80~85로 달라 SongBPM 83을 기준으로 적었습니다. 4/4도 해당 DB 표기입니다. 코드는 B → G♭ → B♭m → E♭m 후보.
- **#16 So Low / #24 AEAO / #34 한계 / #38·#124 영원해 / #86 힙합보단 / #116 Somebody / #143 기적 / #161 지금 이대로만 / #153·#154 다시, 별 아래**: 박자표를 확인하지 못해 **4/4로 단정하지 않고 '미확인'**으로 두었습니다(화면은 4박 카드로 연습). BPM 이견이 있는 곡(힙합보단 77/150, 한계 144/72)은 메모에 병기했습니다.
- **#126 내일을 너에게**: 코드표가 **카포 4 · G·D·Em·C**로 적혀 있어 그 운지 그대로 저장하지 않고, 카포 4에서 실제로 울리는 **B·F♯·G♯m·E**로 옮겼습니다. 계산 결과 카포 +4 · G폼이 나와 코드표와 일치합니다. BPM은 미확인.
- **#152 기억의 온기**: 카포 1 · F·C 코드표 → 소리 키 **F♯·C♯**로 옮겼습니다(카포 +1 · F폼). 확인된 코드가 2개뿐이라 전체 진행이 아닙니다.
- **#153·#154 다시, 별 아래**: 코드 사이트 키 표기는 B(곡 중 전조 가능)이지만 확인된 도입 진행이 **G → D/F♯ → Em7 → C → D**라서 도입 G키로 적고, 전조부 코드는 넣지 않았습니다.
- **#77 사랑이라 믿었던 것들**: 원곡 BIG Naughty (서동현) feat. 이수현(AKMU), 원키 C → D♭ 후반 반음 전조. 연결 영상은 SBS 더 리슨 권진아 듀엣 무대입니다.
- **#139 기대**: 나윤권 원곡(도경수 표기는 오류로 정정), E♭ → E 전조, 100bpm·4/4.
- **#159 서, 어른**: 검색어 '30'의 정식 곡명이 '서, 어른'임을 확인. 악보가 없어 검수 대기이고, 별칭 30은 검색어로 남겼습니다.
- **#205 안녕 너희 / #206 나를 사랑하지 말아요**: 가수는 허각으로 정리하고, 연결 영상이 유영우·허각 듀엣 무대임을 메모에 남겼습니다. 26번은 악보 A키 표기만 확인, 27번은 F키 편곡 악보만 있어 원키로 적지 않았습니다.
- **#202·#203 닮은 사람**: 유료 멜로디 악보만 있어 키·BPM·코드 미확인(검수 대기).
- **#25·#118·#157·#173·#186·#190**: 곡 존재·BPM·유료 악보 등 일부만 확인되어 검수 대기. #173 jehoda(2026 앨범 10번 트랙), #186 정영원(2025-07-17), #190 임승부(2017, 3:24)는 곡 식별 근거만 남겼습니다.
