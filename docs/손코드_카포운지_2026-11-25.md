# STRUM — 14버튼 밖 코드: 편한 카포 + 진짜 코드 운지법 (2026-11-25)

근거: 주성 님 지시 — "카포 써도 없는 코드 있는 노래 있으면 최대한 편한 코드만 남게 카포를 쓴 악보로 만들고, 카포 써도 없는 코드는 진짜 코드로 악보에 손가락 운지법까지 다 나오게 세팅해줘. 최대한 어려운 하이코드 특수코드 텐션코드 안 나오게 카포 세팅해주는 거 잊지 말고."

## 어떻게 골랐나 (규칙)

1. 곡마다 남는 코드(14버튼 밖)를 카포 0~11에서 모두 계산한다. 카포는 손 모양만 옮기므로
   **남자키와 실제 울리는 코드(`sound`)는 절대 바뀌지 않는다.** (버튼 이름 + 카포 = 울리는 음)
2. 후보를 다음 순서로 비교해 하나를 고른다(작을수록 좋음).
   - ① 남는 코드 **종류 수** (SimplifyChord에 넣거나 손으로 익혀야 하는 코드 수)
   - ② **손으로 잡는 마디 부담** = Σ(손 모양 난이도 × 그 코드가 나오는 마디 수)
   - ③ 남는 코드가 나오는 **마디 수**
   - ④ 남는 코드 이름이 14버튼 이름과 겹치는 수(예: 버튼에 `Em`이 있는데 슬롯이 `Em`이면 헷갈림)
   - ⑤ **낮은 카포**
   - 지금 카포가 ①~④에서 같거나 더 좋으면 **그대로 둔다** → 이미 14버튼으로 완주하던 곡은 카포를 건드리지 않는다.
3. 손 모양 난이도는 실제 운지표에서 계산한다: 완전 오픈 0 < 미니·부분 바레 2 < 전체 바레 3(1~4프렛) / 4(5프렛 이상).
4. 7th·maj7·m7·6·sus·add9은 지금까지처럼 3화음 버튼으로 근사하므로, 그 코드가 사라지는 카포도 후보에 들어간다.

### 왜 남는 코드가 대부분 바레인가

14버튼은 **오픈 코드 모양 그 자체**다(C·Dm·Em·F·G·Am·Bdim / Cm·D·E·Fm·Gm·A·Bm).
그래서 14버튼 밖으로 남는 코드의 손 모양은 원래부터 바레 계열(B♭·B·C#·E♭·F#·A♭·F#m·C#m…)이거나
감5·증5화음 같은 특수 코드다. 이번 작업으로 줄어든 것은 **그 바레를 잡아야 하는 마디 수와 코드 종류**이고,
운 좋게 오픈 폼이 남는 경우는 그 폼을 골랐다.

- `verified-021` 「날씨가 좋고 바람도 좋아」: C#7 → **B7 오픈(x21202)** (카포 없이 B♭ 바레가 되던 것을 카포 2로)
- `restored-096` 「And July」: E7 → **B7 오픈(x21202)** (카포 5 유지)
- `playlist-186` 「오늘도 날씨는 흐리네」: Bm7♭5 → **G♭m7♭5(2x221x)**, 4현만 잡는 폼(카포 5)

## 손가락 운지표 만드는 방법 (tools/chord_shapes.py)

- 실제 울리는 코드 + 카포 → **손 모양 코드 = 실제 코드 − 카포**를 구하고, 그 모양의 표준 폼(오픈·E폼·A폼 바레)을 고른다.
- 고른 폼은 **음정으로 검증**한다: 6→1번줄 프렛을 음으로 바꿔 (프렛 + 카포)가 코드 구성음 안에 있는지,
  근음과 3음이 들어 있는지 확인하고, 구성음 밖의 음이 하나라도 울리면 그 폼은 버린다.
- 손가락 번호는 통상 운지(1 검지·2 중지·3 약지·4 소지)를 그대로 쓰고, 바레는 1번 손가락으로 `from~to`번줄을 눌러 표시한다.
- 슬래시 코드(B♭/C, E♭/G)는 코드 모양만 잡고 "베이스는 반주가 잡아 준다"고 적는다(베이스를 손으로 넣으면 오히려 잡기 어려워짐).
- 텐션 코드를 3화음으로 근사한 경우 화면에 `근사`를 적는다.
- 생성기는 `python3 tools/chord_shapes.py`로 자체 점검표를 출력한다.

## 화면에 어떻게 보이나

- **마디 카드(회색 점선)**: `S1`·`S2` 대신 **실제 코드 이름**이 크게, 그 아래 **손 모양**(예: `B♭ 모양`)과 **프렛 코드**(`x13331`)가 작게.
- **악보 탭 상단 '손으로 잡는 코드 N개' 카드**: 코드마다 SVG 운지표(6줄·프렛 눈금·손가락 번호·×/○·바레 막대),
  `x13331` 한 줄 요약, 손가락 안내(`1:5~1번줄 1프렛 바레 …`), 잡는 요령, 왜 남았는지(예: "카포 +4에서는 D 코드가 B♭ 모양이 되어 14버튼에 없습니다").
- **SimplifyChord 탭**: 같은 운지표를 크게 + 어느 마디에 나오는지 + 에어로밴드 앱에 코드 이름을 넣는 방법.
- 완주 곡은 "손으로 잡을 코드 없음 — 14버튼만으로 끝까지 칩니다" 안내만 나온다.
- 읽는 법: 마디 카드의 **큰 글씨 = 실제 울리는 코드**, **작은 글씨 = 카포를 뺀 손 모양**. 버튼 카드는 반대로 큰 글씨가 버튼 이름, 작은 글씨가 실제 울리는 코드다.

## 남는 것·주의

- Capo +8~+10을 쓰는 곡이 15곡 생겼다(카포 0~9 권장 범위를 넘는 값). 이 값들이 아니면 손 코드가 더 남아서다.
  에어로밴드 앱 카포는 25키까지 되므로 앱 설정에는 문제가 없고, 더 낮은 카포를 원하면 손 코드가 조금 늘어난다.
  예) 「바닷가에서」: +10 → 손 코드 0개 / +5 → 1개(2마디) / +3 → 1개(1마디) / +9 → 6개.
  「나의 X에게」(playlist-032·033·188·208): +10 → 0개 / +8 → 1개 / +3 → 1개 / +5 → 1개.
- 운지표 프렛은 **카포를 0프렛으로 본 상대 위치**다(버튼과 같은 기준). 화면 안내에도 그렇게 적었다.
- 손 코드의 실제 음정 검증은 코드 구성음 기준이다. 같은 코드라도 연주자 손 모양(운지 선택)은 달라질 수 있다.
