# STRUM — AeroBand 버스킹 기타 학습 사이트 (복원·정리 패키지 · 피클 인계용)

**이 패키지는 기존 공개 Sites 페이지를 참고해 새로 구현한 독립 실행 버전입니다. 기존 Sites의 원본 저장소나 전체 152곡 DB를 복사한 것이 아닙니다.**

- 기존 사이트: https://aeroband-busking-jc.actualtide8.chatgpt.site/
- 원래 플레이리스트: 유튜브 영상 **211개** (이 숫자는 영상 수)
- 기존 Sites 표시: 선별 버스킹곡 **152곡** (이 숫자는 곡 수)
- 이전 기록상 접근 불가: 영상 **42개**. 어떤 번호가 접근 불가였는지 전체 대응표는 확보되지 않았으므로 자동 지정하지 않았습니다.
- 이 복원본에서 **이전 대화에서 확인·입력한 곡 정보: 25건(가수 미확인 1건 포함)**, 별도 **입문 추천곡 1곡**. 152곡 전체를 갖고 있다고 표시하지 않습니다.
- 원본 #6의 7곡, #65의 2곡은 각각 서로 다른 곡으로 관리합니다.
- 원본 #163은 '제외' 상태를 유지합니다.

**YouTube 영상 보기:** 정확한 영상 URL을 넣으면 사이트 안에서 YouTube 공식 임베드로 재생합니다. URL이 없으면 검색 버튼을 제공합니다. 일부 영상은 소유자가 임베드를 제한할 수 있습니다.

**음악 듣기:** 허가된 MP3 등의 직접 오디오 URL 또는 이용자가 기기에 보관한 오디오 파일을 사이트 안에서 재생합니다. 소유 음원/URL이 없다면 YouTube Music 검색 화면을 별도 탭으로 엽니다. YouTube에서 음원 무단 추출/숨김 재생 기능은 구현하지 않았습니다.

**기록:** localStorage를 사용해 **같은 브라우저**에서는 유지되지만 다른 휴대전화로 자동 동기화되지는 않습니다. 주기적으로 전체 JSON을 백업하십시오.

## 실행

별도 npm 패키지가 필요 없습니다.

1. 압축파일을 해제합니다.
2. `index.html`을 최신 Chrome, Edge, Safari에서 엽니다. 일부 브라우저는 file://에서 기능을 제한할 수 있으므로 웹 서버를 권장합니다.
3. 로컬 서버가 있으면 프로젝트 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 방문.
4. 무료 정적 호스팅(GitHub Pages 또는 Cloudflare Pages 등)에 폴더 내용을 그대로 올려 배포할 수 있습니다. 빌드 명령은 필요 없습니다.
5. **원본 Sites에 코드를 덮어쓰지 마세요.** 먼저 원본 데이터 전체를 백업한 후 새 프로젝트로 시험합니다.

## 데이터 구조

```
STRUM_busking_source/
├── index.html
├── manifest.webmanifest
├── src/
│   ├── seed.js              # seed JSON을 window.STRUM_SEED로 삽입(외부 API 불필요)
│   ├── app.js               # 화면·기능 전체 코드
│   └── styles.css           # PC/모바일 반응형 디자인
├── data/
│   ├── metadata.json        # 복원 근거와 한계
│   ├── songs.seed.json      # 확보된 25곡 항목 + 추천 1곡
│   ├── songs.verified.csv   # 25곡의 정보(가수 미확인 1곡 포함) 표
│   ├── source-videos.seed.json # #1~#211 전체 번호 슬롯
│   └── source-videos.slots.csv # 211개 번호 관리용 표
├── docs/
│   ├── 학습과_곡목록_정리.md
│   └── 기존사이트_데이터복원.md
└── tools/
    ├── generate_seed.py     # seed JSON/JS 재생성 스크립트
    └── verify_data.py       # 211 번호와 곡 자료 정합성 검사
```

### 곡 구조 (`data/songs.seed.json`)

- `id`: 내부 고유 식별자
- `title`, `artist`: 곡명/가수
- `sourceIndices`: 원본 영상 번호 배열(예: `[6]`)
- `verification`: 확인 근거 (`site-top3`, `user-verified`, `learning-recommendation-not-in-original-playlist`)
- `videoUrl`: 직접 확인한 YouTube URL(없으면 빈 문자열)
- `audioUrl`: 본인이 사용권을 가진 오디오 링크(없으면 빈 문자열)
- `key`, `maleKey`, `bpm`: 원곡 키 / 편곡 키 / 템포(모르면 '미확정' 또는 null)
- `chords`, `chordStatus`, `strumming`: 코드 / 검수 상태 / 스트로크
- `level`: 미착수 / 연습 중 / 거의 가능 / 버스킹 가능
- `setlist`: 실제 버스킹 세트리스트 포함 여부
- `notes`: 어려운 부분, 근거, 보류 사유

### JSON 가져오기 형식

```
{ "songs": [ {"id":"...","title":"곡명","artist":"가수", "sourceIndices":[2],"level":"연습 중"} ],
  "sources": [ {"index":1,"status":"미확인","url":"","note":""} ],
  "logs": [] }
```

`sourceIndices`는 **영상 번호**, 곡 개수가 아닙니다. 원본 #6에 7곡이 있어도 동일한 원본 번호 #6을 모두 공유합니다. 기존 데이터의 곡 ID와 숙련도는 가능하면 유지하십시오.

CSV 열은 `title,artist` 필수이며 `sourceIndices`는 `6|65`처럼 복수 값을 입력할 수 있습니다. 백업 JSON을 가져오면 연습 일지와 원본 상태까지 복원됩니다.

## 완료하지 않은 부분

- **원본 152곡 전부의 곡명·가수·링크 복원 미완료**: 현재 대화 자료에 없는 데이터는 추측하지 않았습니다. 기존 Sites 편집 코드 또는 원본 152곡 CSV/JSON을 가져와야 정확히 완성됩니다.
- **211개 영상의 URL 전체 복원 미완료**: 번호와 연결이 확보된 25곡 항목만 시드에 삽입했습니다.
- **접근 불가 42개 각 번호 특정 미완료**.
- 직접 청음 검증, 남자 키 완전 확정, 전체 곡 코드 분석 미완료. 이미 `notes`에 있는 코드 후보도 검증 전으로 표기했습니다.
- 계정 기반 클라우드 동기화, 다기기 로그인, 오디오 저작권 라이선스 서비스 연동, 영상 원본 자동 다운로드는 없음.
