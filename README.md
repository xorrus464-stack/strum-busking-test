## 실행

별도 npm 패키지가 필요 없습니다.

1. 압축파일을 해제합니다.
2. `index.html`을 최신 Chrome, Edge, Safari에서 엽니다. 일부 브라우저는 file://에서 기능을 제한할 수 있으므로 웹 서버를 권장합니다.
3. 로컬 서버가 있으면 프로젝트 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 방문.
4. 무료 정적 호스팅(GitHub Pages 또는 Cloudflare Pages 등)에 폴더 내용을 그대로 올려 배포할 수 있습니다. 빌드 명령은 필요 없습니다.
5. **원본 Sites에 코드를 덮어쓰지 마세요.** 먼저 원본 데이터 전체를 백업한 후 새 프로젝트로 시험합니다.

### 곡 구조 (`data/songs.seed.json`)

- `id`: 내부 고유 식별자
- `title`, `artist`: 곡명/가수
- `sourceIndices`: 원본 영상 번호 배열(예: `[6]`)
- `verification`: 확인 근거 (`site-top3`, `user-verified`, `user-title-only`, `archive-restored`, `user-confirmed-playlist`, `playlist-public-video`, `learning-recommendation-not-in-original-playlist`)
- `videoStatus`: `공개 영상*` 또는 `영상 불가(사유)`. 영상 불가 곡은 `videoUrl`이 비어 있습니다.
- `videoUrl`: 직접 확인한 YouTube URL(없으면 빈 문자열)
- `audioUrl`: 본인이 사용권을 가진 오디오 링크(없으면 빈 문자열)
- `key`, `maleKey`, `bpm`, `timeSignature`: 원곡 키 / 남자키 / 템포 / 박자(모르면 '미확정' 또는 null)
- `chart`: 원터치 악보 데이터 — `originalKey`, `maleKey`, `maleShift`, `capo`, `formText`, `timeSignature`, `bpm`,
  `sections[{name, bars[[{btn, slot, sound, orig}]]}]`, `slots[{slot, chord, orig, alt}]`, `stage`, `percussiveReady`,
  `stroke`, `percussive`, `coverage`, `evidence[{label,url,note}]`
- `chartStatus`: `ready`(악보 완성) / `partial`(키·박자·BPM·코드 후보까지 확인) / `pending`(코드 검수 대기 — 확인된 BPM·키·근거 링크만 `chart`에 남김) / `reference`(비음악·참고 영상) / `original`(자작곡)
- `category`·`workTitle`·`workArtist`: 재생목록 영상 항목을 곡 단위로 묶는 분류값(영상 제목은 그대로 보존)
- `chords`, `chordStatus`, `strumming`: 코드 / 검수 상태 / 스트로크
- `level`: 미착수 / 연습 중 / 거의 가능 / 버스킹 가능
- `setlist`: 실제 버스킹 세트리스트 포함 여부
- `notes`: 어려운 부분, 근거, 보류 사유

### JSON 가져오기 형식

```
{ "songs": [ {"id":"...","title":"곡명","artist":"가수", "sourceIndices":[2],"level":"연습 중"} ],
  "sources": [ {"index":1,"status":"미확인","url":"","note":""} ],
  "logs": [] }
```

`sourceIndices`는 **영상 번호**, 곡 개수가 아닙니다. 원본 #6에 7곡이 있어도 동일한 원본 번호 #6을 모두 공유합니다. 기존 데이터의 곡 ID와 숙련도는 가능하면 유지하십시오.

CSV 열은 `title,artist` 필수이며 `sourceIndices`는 `6|65`처럼 복수 값을 입력할 수 있습니다. 백업 JSON을 가져오면 연습 일지와 원본 상태까지 복원됩니다.

## 완료하지 않은 부분

- **원본 152곡 전부의 곡명·가수·링크 복원 미완료**: 재생목록에 없는 곡은 추측하지 않았습니다. 기존 Sites 편집 코드 또는 원본 152곡 CSV/JSON을 가져와야 정확히 완성됩니다.
- **공개 영상 155곡의 원곡 가수·코드·키·BPM 미확인**: 유튜브 제목/채널만 기록했습니다.
- **접근 불가 23곡의 제목 미복원**: 공개 출처로 확인 불가.
- **실제 영상 재생 확인 미완료**: 이 작업 환경은 YouTube가 봇으로 판정해 재생을 확인할 수 없었습니다.
- **남자키·악보는 161개 항목** 에 넣었습니다(악보 완료 124 + 부분 확인 37, 자작 항목 1개는 별도). 2026-11-22 음원 분석으로 기존 검수 대기 9곡이 모두 부분 확인으로 올라가 검수 대기 곡은 0개입니다. 분석값이지만 청음·정식 악보 대조 전이라 곡 정보와 악보 화면에 그 사실을 적었습니다.
- 악보의 마디 배치는 코드스코어 공개 미리보기(4행=16마디)를 4박 카드로 옮긴 **연습용 배치**입니다. 원곡의 세부 마디와 다를 수 있으며, 모든 곡의 근거 링크를 악보 화면 '근거' 탭에 넣었습니다.
- 마디 배치는 확인한 코드표의 순서를 4박 마디 카드로 정리한 **연습용 배치**입니다. 원곡의 세부 마디 배치(2박/4박 전환, 세컨더리 도미넌트 등)는 악보로 다시 확인해야 합니다.
- 직접 청음 검증은 하지 않았습니다. 코드·키·BPM은 공개 코드표/악보 메타데이터(chordwiki, ezcho, Chordify, SongBPM, 악보바다 등)에서 옮긴 값이며 곡별 근거 링크를 `docs/악보_데이터_2026-11-22.md`에 남겼습니다.
- 계정 기반 클라우드 동기화, 다기기 로그인, 오디오 저작권 라이선스 서비스 연동, 영상 원본 자동 다운로드는 없음.
